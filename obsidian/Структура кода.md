# Структура кода

Часть проекта [[Neon Requiem]]. Запуск и проверки — в [[Стек и запуск]].

## Папки

```
autoload/                синглтоны (список ниже)
assets/                  код-нарисованный пиксель-арт: tiles/, sprites/ (листы), icons/ (items, abilities, meta)
core/                    Db (таблицы JSON), Fmt (текст), Neon (линии и кольца эффектов), Sprites (листы спрайтов)
data/                    весь баланс: config, heroes, abilities, items, enemies, elites, bosses,
                         locations, meta_tree, difficulty, tiles, sprites (манифест листов), hub (комната и терминалы)
scenes/MainMenu.tscn     главное меню   scenes/scripts/MainMenu.gd (главная сцена)
scenes/Hub.tscn          хаб-локация    scenes/scripts/Hub.gd
scenes/hub/              HubRoom (собирается), HubAvatar, Terminal, окна терминалов (HubOverlay +
                         SkillTree, Workshop, HeroSelect, Stats, Portal)
scenes/Run.tscn          забег          scenes/scripts/Run.gd, RunSpawner.gd
scenes/entities/         Player, Enemy, EliteEnemy, Boss, Projectile, Pickup, Drone
scenes/entities/components/  PlayerAttack, AbilityCaster, ShotFactory, EliteModifier, HeroAnimator, ReloadBar,
                         WeaponHolder (оружие в руке, дуло)
scenes/ui/               HUD, LevelUpModal, InventoryOverlay, PauseMenu, GameOverModal,
                         LoopChoiceModal, HeroDraftModal
scenes/ui/components/    AbilitySlot, ItemCard, StatRow, ModalBase, JuicyBar (шкалы), DifficultyBar (полоса сложности),
                         HeroCard (карточка героя со спрайтом)
scenes/fx/               SpriteFx.gdshader (+ материалы), DamageNumber, ScreenShake, Lightning (молния),
                         Backdrop (ночной город за картой)
scenes/Locations/        5 локаций + LocationBase.gd, tiles/ (атлас и TileSet)
theme/                   main_theme.tres
tools/                   сборщик мира, линт, строгая проверка, смоук- и нагрузочный тесты
tools/art/               генераторы пиксель-арта 16×16 на Python (тайлы и блоки, существа, герои и оружие, иконки, эффекты)
tools/shots/             скриншоты для визуальной проверки (локации, игровой тур, меню и хаб)
obsidian/                эта карта
```

## Автозагрузки (в порядке загрузки)

| Синглтон | Что |
|---|---|
| `Signals` | шина событий: все сигналы игры объявлены только здесь |
| `InputMapHelper` | действия ввода по умолчанию из `config.json`, переназначение, подписи клавиш |
| `TimeService` | unix-время для сохранений и часы забега без пауз (`run_msec`) |
| `SaveManager` | чтение и запись двух файлов сохранения, версии и миграции |
| `LootRoller` | взвешенные броски и дроп; своего RNG нет, берёт `GameState.rng` |
| `DamageCalc` | **чистый**: исходящий урон, криты, броня, щиты, вампиризм, шипы |
| `WaveDirector` | **чистый**: шаг уровня угрозы, множители, лимит врагов, броски элитных модификаторов, параметры петли |
| `SpawnDirector` | **чистый**: (локация, таблицы, уровень, окно времени, зерно) → события спавна |
| `ItemSystem` | стаки, бонусы, эффекты при попадании и убийстве, рецепты, броски редкости, перезарядка активных предметов |
| `AbilitySystem` | шаблоны способностей, уровни 1–5 и ульта, мана и перезарядка по слотам |
| `AudioBus` | заглушка: только выключение звука |
| `MetaState` | мета-прогресс: банк, герои, древо, уровни стартовых предметов, статистика |
| `GameState` | состояние забега и единственный `RandomNumberGenerator` |

## Правила кода

- **Одно изменяемое состояние.** Забег живёт в `GameState`, мета — в `MetaState`; меняются только их методами, сигналы уходят после пачки изменений (по одному на домен).
- **Шина сигналов.** Интерфейс читает состояние только из сигналов и шлёт намерения обратно через `Signals`.
- **Без ссылок между сценами.** Сущности просят спавн через `Signals` (`projectile_requested`, `pickup_requested`, `drone_requested`…), `Run` вызывает `setup()` сверху вниз.
- **Чистые модули.** `SpawnDirector`, `WaveDirector`, `DamageCalc` получают всё аргументами, случайность — хеш от зерна.
- **Баланс только в данных.** Числа лежат в `data/*.json`, скрипты читают их через `core/Db.gd`.
- **Время.** Таймеры и перезарядки сравниваются с `TimeService.run_msec()`, поэтому замирают на паузе.
- **Стиль.** Явные типы, функции до 40 строк, `push_error()` вместо `print()`, `TileMapLayer` вместо `TileMap`.

## Дерево сцены забега

```
Run (process ALWAYS)
├── WorldEnvironment        свечение
├── World (PAUSABLE)
│   ├── LocationSlot        текущая локация
│   ├── Pickups / Enemies / Projectiles / Drones / Fx
│   └── Player
├── Camera (ScreenShake.gd)
├── Spawner (RunSpawner.gd) события SpawnDirector и запросы с шины → узлы
├── UI (CanvasLayer)        HUD и все модальные окна
└── FadeLayer               затемнение переходов
```

Модальные окна сообщают `modal_visibility_changed`, и `Run` ставит дерево и часы забега на паузу, пока открыто хоть одно окно.
