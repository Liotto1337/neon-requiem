# Интерфейс

Часть проекта [[Neon Requiem]]. Интерфейс читает состояние только из сигналов `Signals`, см. [[Структура кода]].

## Управление

| Клавиши | Действие |
|---|---|
| WASD | движение (физические клавиши, работает на русской раскладке) |
| Мышь | прицел |
| ЛКМ / ПКМ | базовая и усиленная атака |
| R | перезарядка / парирование / отзыв дронов |
| Z X C V (+B) | способности, B — после «Предела» |
| 1–6 (+7) | активные предметы, 7 — после «Предела» |
| ESC | пауза |
| TAB | инвентарь и крафт |

Клавиши переназначаются через `InputMapHelper`, выбор сохраняется в `user://input_map.json`.

## HUD

- Слева сверху: HP с полоской щита, мана, уровень и опыт, кредиты, статус (антихил, щит, активные усиления).
- По центру сверху: таймер забега, локация (N/5), уровень угрозы, петля и множитель; полоса босса или минибосса.
- Внизу: слоты способностей (глиф, клавиша, уровень, «УЛЬТ», перезарядка) и слоты активных предметов; слева — патроны или готовность действия R.
- Всплывающие сообщения: трофеи, «Не хватает маны», переходы, петли.

## Модальные окна

Пока открыто любое окно, игра стоит на паузе.

| Окно | Когда | Что внутри |
|---|---|---|
| Стартовое снаряжение | начало забега | 3 карточки, выбрать 2 |
| Новый уровень | повышение уровня | 3 варианта, мышь или клавиши 1–3 |
| Инвентарь (TAB) | по клавише | характеристики, способности, пассивные и активные предметы, доступные рецепты |
| Пауза (ESC) | по клавише | продолжить, звук, выйти в хаб с сохранением |
| Сигнал потерян | смерть | итоги и возврат в хаб |
| Реквием завершён | финальный босс | в хаб с кредитами или новая петля |

## Оформление

- Тема `theme/main_theme.tres`: тёмные панели с циановой рамкой, кнопки с маджентовой рамкой, при наведении циан.
- Карточки `ItemCard` окрашиваются по редкости или цвету способности; в инвентаре они компактные, а описание показывается во всплывающей подсказке.
