# Стек и запуск

Часть проекта [[Neon Requiem]].

## Стек

| Что | Зачем |
|---|---|
| Godot 4.7, GDScript | движок и весь код |
| GL Compatibility | одинаково для Web и Windows |
| WorldEnvironment + Glow | неоновое свечение, порог 0,8, `hdr_2d` включён |
| Python 3 | `tools/lint.py` — проверка соглашений |
| Python 3 + numpy, Pillow | `tools/art/` — генераторы пиксель-арта |
| codeart2d + resvg-py | риги и анимации героев (`rig_animate.py`) |

Сторонних аддонов нет. Весь арт нарисован кодом и лежит в `assets/`, подробнее в [[Графика и анимации]].

## Экран

- База 1920×1080, растяжение `canvas_items`, `aspect=expand`.
- На Windows игра запускается во весь экран, на Web — в окне (`window/size/mode.web=0`).
- Фильтр текстур nearest (пиксель-арт), тема интерфейса — `theme/main_theme.tres`.

## Запуск

1. Открыть папку в Godot 4.7 и дождаться первого импорта. Главная сцена — `scenes/MainMenu.tscn`.
2. F5: главное меню с 200 кредитами и открытым Вектором → «Войти в хаб» → подойти к порталу и нажать E.
3. Отладочные клавиши (только debug-сборка): **F10** — перемотать время забега на 60 с, **F9** — опыт и кредиты.
4. Сохранения: `user://meta_save.json` (мета), `user://run_save.json` (забег), `user://settings.cfg` (звук), `user://input_map.json` (переназначенные клавиши).

## Экспорт

- **Web (Яндекс Игры):** пресет Web, Thread Support выключен, в «Фильтры не-ресурсных файлов» добавить `data/*.json`. В архив — файлы сборки с `index.html` в корне.
- **Windows:** пресет Windows Desktop с тем же фильтром `data/*.json`.
- Пресеты (`export_presets.cfg`) в git не попадают.

## Проверки

```bash
GODOT=/путь/к/Godot_v4.7 tools/check.sh          # линт, строгая компиляция, смоук-тест
GODOT=/путь/к/Godot_v4.7 SOAK=1 tools/check.sh   # + нагрузочный тест на ~3 минуты
godot --headless --path . res://tools/BuildWorld.tscn   # пересобрать TileSet и локации
GODOT=/путь/к/Godot_v4.7 tools/art/rebuild.sh   # перерисовать арт, импортировать, пересобрать мир
```

Визуальная проверка (нужен виртуальный дисплей):

```bash
SHOTS_OUT=<папка> xvfb-run -a -s "-screen 0 1920x1080x24" godot --path . --rendering-driver opengl3 res://tools/shots/LocationShots.tscn
SHOTS_OUT=<папка> SHOT_HERO=katar xvfb-run -a -s "-screen 0 1920x1080x24" godot --path . --rendering-driver opengl3 res://tools/shots/GameShots.tscn
SHOTS_OUT=<папка> xvfb-run -a -s "-screen 0 1920x1080x24" godot --path . --rendering-driver opengl3 res://tools/shots/HubShots.tscn
```

- `tools/lint.py` — функции не длиннее 40 строк, нет `print()`, RNG только в `GameState`, чистые модули без ссылок на узлы, все сигналы в `Signals.gd`, явные типы.
- Строгая компиляция — все скрипты грузятся с предупреждениями GDScript, поднятыми до ошибок (через временный `override.cfg`).
- Смоук-тест (`tools/smoke/SmokeTest.tscn`) — 79 проверок: список приёмки плюс главное меню, хаб-локация с терминалами, анимации героя, полоса перезарядки, камера и HUD; отчёт в `user://smoke_report.txt`.
- Нагрузочный тест (`tools/smoke/SoakTest.tscn`) — три героя проходят все пять локаций со всеми способностями, предметами, врагами и боссами.

## Конфигурация

- `.gitignore`: `.godot/`, `*.import`, `export/`, `export_presets.cfg`, `__pycache__/`, `override.cfg` (временный файл строгой проверки).
- В `project.godot` выключено предупреждение `unused_signal` (сигналы объявлены в общей шине), `untyped_declaration` — предупреждение.
- Действия ввода прописаны в `project.godot` и продублированы в `data/config.json` → `input`: `InputMapHelper` добавит недостающие.
